# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |

Security fixes land on `main`. Each `node-ai-*` folder is a template you can copy. After you copy one, track the versions your own project still supports.

## Reporting a vulnerability

Report security issues through [private vulnerability reporting](https://github.com/poluru-labs/node-api-starter/security/advisories/new) on this repository (Security → Advisories → Report a vulnerability).

Do not open a public issue, pull request, or discussion for a security problem.

Please include:

- The service folder, for example `node-ai-sensitive-data-filter`
- The version or commit
- The affected endpoint or file
- A way to reproduce the issue

We aim to acknowledge a report within 3 business days.
